# 使用指南

## 开始一场会议

1. 在“会议”页面点击“开始会议”。
2. 确认会议名称、音频来源、存储空间和 AI 服务状态。
3. 桌面端可选择麦克风、系统音频或双轨输入；普通浏览器仅使用浏览器允许的音频能力。
4. 点击开始后，确认顶部录音与转写状态已进入运行中。

会议只会在用户明确操作后开始采音。首次使用麦克风时，系统可能显示权限请求。

## 会中工作台

- **连续文字**：查看暂定、确认和后续校正的转写内容。
- **当前议题**：了解正在讨论的主题和已识别的事实。
- **AI 建议**：查看当前最值得确认的问题；展开“查看依据”可定位对应原文。
- **会议控制**：暂停、继续或结束会议，并观察录音、转写与 AI 状态。

建议是辅助信息，不会自动替团队确定负责人、截止时间或技术结论。

## 会后复盘

会议结束后会进入复盘页面。顶部标签用于切换：

- **复盘**：摘要、方案与风险、待确认项和建议处理结果。
- **文字**：完整转写，可回到对应时间点。
- **录音**：播放已保存的会议录音与处理后的音频。
- **文档**：查看和编辑会议纪要等派生文档。

分析仍在运行时，界面会显示处理中状态；失败时会保留可重试入口，而不是用空内容代替结果。

## 导入录音

1. 在“会议”页面点击“导入录音”。
2. 选择支持的音频文件并填写会议名称。
3. 提交后在历史列表查看转写和分析进度。
4. 任务完成后打开会议进入复盘。

请勿在任务执行期间移动应用正在管理的内部音频文件。原始导入文件是否保留，以导入窗口中的选项和当前版本行为为准。

## 管理历史会议

历史列表支持搜索、状态筛选和排序。会议菜单提供重命名和删除。删除是不可逆操作，会同时清理该会议受控目录中的数据库记录、录音和派生任务；操作前请先导出需要保留的内容。

## 个人笔记

“笔记”用于保存不必绑定某场会议的个人内容。可新建、编辑、搜索和删除笔记。笔记与会议数据一样保存在本地数据目录中。

## 离线能力

“离线能力”页面用于查看实时识别、录音转写及其运行时状态，并导入 `.mcpkg` 能力包。基础客户端不自带 ASR 模型；未导入兼容能力包时，相关能力会显示未安装或不可用，这不是网络故障。

导入前确认能力包来源可信、平台为 Windows x64，并预留约 9 GB 磁盘空间。选择“导入离线包”后保持应用运行，等待平台、清单、路径和文件哈希全部校验完成。导入成功后按界面提示激活或重启，再确认实时识别和录音转写均显示“已就绪”。

校验失败时不要手动解压、改名或替换包内文件。请保留界面显示的错误信息，并参考 [故障排查](troubleshooting.md)。当前公开仓库和 GitHub Release 不提供完整离线能力包。

## AI 服务设置

在“设置”中配置 OpenAI-compatible 服务：

1. 填写服务地址、API Key 和模型。
2. 选择接口风格。
3. 执行连接检测。
4. 检测成功后保存。

远程服务不可用时，本地会议记录和转写仍可使用；AI 建议、摘要或文档分析会进入未配置、暂停或失败状态。
