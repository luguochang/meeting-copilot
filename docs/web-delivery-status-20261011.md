# 网页版功能与交付状态

日期：2026 年 10 月 11 日。本文用于说明当前可交付范围、已知限制和需要完成的验收。操作步骤见[用户操作手册](realtime-participation-user-manual-20261008.md)，运行环境与启动方法见[网页版部署说明](web-deployment.md)。

当前定位是运行在使用者电脑上的单用户会议助手：接收语音、保存识别文字，在讨论过程中辅助提出追问、比较方案和组织回应，再把确认后的文稿与资料用于后续会议。提供功能入口与持久化流程，和证明整场会议效果稳定，是两项不同的交付要求。

## 当前功能范围

| 能力 | 当前实现与使用边界 |
| --- | --- |
| 会前准备 | 检查存储、识别状态、麦克风与录音告知；主题、角色和资料可选。打开准备页不会自动采音。 |
| 本场校对模式 | 可选本地精修＋大模型校对或仅大模型校对；保存会议设置，开始时复查并记录实际模式。 |
| 资源说明与保护 | 显示实际可用内存、总内存与离线精修门槛。明确容量不足时说明回退模式；探针未知或组件故障需显式处理，保护门槛保持生效。 |
| 实时正文 | 保存正式识别文字，临时草稿独立更新；区分识别原文、校对处理中、已校对、校对未改字和失败保留原文。 |
| 实时教练 | 自动建议和“我可以问什么 / 还有什么方案 / 帮我组织回应”三个主动入口，支持查看依据与过去建议。建议需核对时点、来源和当前话题。 |
| 自己提问 | 选择文字、最近讨论、章节、整场会议或本场资料；可保存回答为笔记。依赖已配置的模型。 |
| 本场文件 | DOCX、文本 PDF、TXT、MD 后台转换；核对正文、修订版本并明确允许范围后，用于本场背景。 |
| 会后整理 | 纪要、分析建议、内容索引及原文质量状态；失败任务重试、人工终稿编辑、版本与保存状态、录音回看。 |
| 笔记与资料库 | 笔记可编辑、归档和按来源回看；资料按项目/文件夹管理，草稿经过确认后供后续会议选择。 |
| 项目延续 | 保存人工终稿入库；项目状态、Wiki、术语和偏好通过独立确认流程复用。入库不自动代表项目状态已更新。 |
| 录音导入与导出 | 导入常见音视频文件；会议导出 Markdown、Word 或 JSON，项目已确认资料可导出 ZIP。实际转换依赖本机组件。 |
| AI 与数据设置 | OpenAI-compatible 服务、协议与通用/实时/校正模型设置；功能通道状态、数据保留策略和选择范围的本地删除。 |

## 当前限制

- **网页版声音来源**：通过浏览器麦克风采音。Windows 系统音频直采与双轨是桌面采集路径，网页版尚不能按同等能力交付。用麦克风收外放会受到环境噪声、回声和设备设置影响。
- **本地资源**：离线模型冷启动与推理需要可用提交额度和空闲物理内存。门槛是保守启动余量；选择仅大模型可省去离线精修，仍需在线语音识别可用。低配电脑整场兼容性和双模型峰值尚需验证。
- **实时效果**：转写速度、关键事实准确率、建议可说出口程度与增量价值，受声音、模型和远端服务影响。尚无覆盖代表性长会议的完整质量和延迟认证。
- **校对边界**：校对未改字表示有效调用后未改文；已校对表示结果经过现有核对并保存，仍不能保证语义恢复正确。未通过核对时保留原文。历史补识别文字与实时大模型校对的统一衔接尚不完整，部分恢复文字仍需人工核对。
- **文档转换**：以简单文本为主。扫描 PDF、图片、复杂表格和版式还原没有完整 OCR 能力保证；转换成功仍需检查内容。
- **上下文与资料**：使用保存的会议范围与相关片段，不保证每次读完所有文件或长会议全文。资料确认、项目事项确认和术语偏好复用需要明确操作；不宣称已经实现自动训练或无限记忆。
- **多人声音归属**：未将可靠的多人说话归属、重叠语音和复杂背景音乐处理列为当前交付保证。
- **模型依赖**：连接测试验证最小工具调用。校对、实时教练、问答和会后整理各自仍可能排队、失败或超时；设置已保存不等于所有功能已通过实用验收。
- **部署范围**：当前按本机单用户服务使用。公开源码和操作文档不等于已交付多人公网托管；对外服务还需要认证、用户隔离、配额与 HTTPS/WSS 等工作。

## 接收者验收清单

安装完成后，用接收者自己的环境、声音与模型配置验收。以下清单保持开放，不以演示截图或构造测试替代实际使用：

- [ ] 浏览器能打开工作台；实际加载的页面与运行的服务版本一致。
- [ ] 打开会前准备、切换模式和查看资源不自动请求麦克风或调用远端模型；显式麦克风检查和正式开始符合页面告知。
- [ ] 两种校对模式保存和刷新一致，已开始会议不能被中途切换。
- [ ] 明确资源拒绝、资源未知、本地模型准备失败和 AI 缺配置的提示分别可理解；回退模式与实际执行一致。
- [ ] 使用一段真实录音或授权麦克风测试，确认正式正文持续追加，旧正文不会被新草稿覆盖，刷新后仍可回看。
- [ ] 校对修改、未改字、失败保留原文和混合覆盖状态符合实际；重要数字、人名和否定词可核对。
- [ ] 使用代表性需求讨论，检查主动追问、替代方案与组织回应是否当场有价值；记录可用建议的等待时间与误导情况。
- [ ] 文件转换、正文修正、授权范围与版本引用一致；未启用或越界资料不会被当作本场背景。
- [ ] 会后正常与失败路径均可处理：原文保留、对应任务重试、人工终稿保存、刷新与导出内容一致。
- [ ] 笔记/终稿入库生成待确认草稿，确认后在下次会议选定范围才能复用；旧来源变化有明确提示。
- [ ] 在约定时长的连续录音中核对保存完整性、页面可读性、资源占用、结束收敛和进程释放。
- [ ] 在目标浏览器与设备完成最终人工验收后，再决定发布版本与分发方式。
